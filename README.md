## English Version

### 📌 Project Overview
**HaulFlow** is a specialized logistics system designed to monitor and validate hauling operations through structured field verification. The system ensures data accuracy by requiring active driver participation from manual checkpoint documentation to a streamlined self verification process at the weighbridge.

This repository serves as a professional portfolio to demonstrate technical writing skills, system logic mapping, and user-centric documentation.

### 🛠️ Documentation Modules
*   **[User Guide](./USER_GUIDE.md)**: Operational workflow for Drivers and Fleet Admins.
*   **[System Flow](./SYSTEM_FLOW.md)**: Logic mapping of task statuses and diagrams to explain data migration between modules.
*   **[Status Lifecycle & Glossary](./GLOSSARY.md)**: Definition of technical terms and software statuses (e.g., *CMS, Dropdown, Widget*).

### 🚀 Technical Writing Approach
*   **Visual Documentation**: Leveraging diagrams to explain complex hauling transitions and checkpoint flows.
*   **Docs-as-Code**: Written in Markdown for version control compatibility.
*   **UI/UX Focus**: Documenting specific design elements like callout annotations and optimized search layouts to improve user task success rates.

## Versi Bahasa Indonesia

### 📌 Ringkasan Proyek
**HaulFlow** adalah sistem logistik khusus yang dirancang untuk memantau dan memvalidasi operasional pengangkutan melalui verifikasi lapangan yang terstruktur. Sistem ini memastikan akurasi data melalui partisipasi aktif driver mulai dari dokumentasi checkpoint manual hingga proses verifikasi mandiri yang efisien di jembatan timbang.

Repository ini berfungsi sebagai portofolio profesional untuk menunjukkan keahlian *technical writing*, pemetaan logika sistem, dan dokumentasi yang berpusat pada pengguna.

### 🛠️ Modul Dokumentasi
*   **[Panduan Pengguna](./USER_GUIDE.md)**: Alur kerja operasional untuk Driver dan Admin Armada.
*   **[Alur Sistem](./SYSTEM_FLOW.md)**: Pemetaan logika status tugas dan diagram untuk menjelaskan perpindahan data antar modul.
*   **[Glosarium & Status](./GLOSSARY.md)**: Definisi istilah teknis dan status perangkat lunak (contoh: *CMS, Dropdown, Widget*).

### 🚀 Pendekatan Dokumentasi
*   **Dokumentasi Visual**: Menggunakan diagram untuk menjelaskan transisi hauling dan alur checkpoint yang kompleks.
*   **Docs-as-Code**: Ditulis dalam format Markdown agar kompatibel dengan kontrol versi (Git).
*   **Fokus UI/UX**: Mendokumentasikan elemen desain spesifik seperti anotasi *callout* dan tata letak pencarian yang dioptimalkan untuk meningkatkan efisiensi pengguna.

# 🚛 Hauling & Logistics Documentation

Repository ini berisi dokumentasi operasional untuk sistem manajemen pengangkutan material dan integrasi penagihan otomatis.

## 📖 Tentang Proyek
Sistem ini menangani alur kerja dari pembuatan **Quotation**, pelaksanaan **Hauling (Task)**, hingga penerbitan **Invoice**. Fokus dokumentasi ini adalah memastikan sinkronisasi data antar modul berjalan akurat.

## 📂 Daftar Isi
1. [Panduan Pengguna (User Guide)](./USER_GUIDE.md) - Langkah demi langkah operasional lapangan.
2. [Logika Status & Alur](./FLOW.md) - Penjelasan teknis perpindahan status data.
3. [Manajemen Member](./MEMBER_GUIDE.md) - Panduan pengelolaan data pelanggan.

## 🛠️ Metodologi Penulisan
Dokumentasi ini disusun dengan pendekatan **User-Centric**, menggunakan elemen visual seperti:
- **Mermaid Diagrams** untuk alur logika.
- **Callout Annotations** untuk informasi kritikal.
- **Tables** untuk referensi status sistem.
